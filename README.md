# 🍔 Yum2MyTum – Food Ordering Website

Yum2MyTum is a food ordering web application designed to make food ordering simple, convenient, and user-friendly. It provides an interactive platform where users can explore food options, place orders, and track their deliveries.

The platform supports food ordering within college campuses as well as across Mumbai, offering a convenient digital food ordering experience.

## 🌐 Live Demo

🔗 **[Yum2MyTum – Live Website](https://yum2mytum.onrender.com/)**

## 🚀 Features

- **Food Browsing:** Explore available food items through an interactive interface.
- **Campus Food Ordering:** Convenient food ordering within college campuses.
- **Mumbai-Wide Ordering:** Designed to support food ordering beyond college campuses.
- **Shopping Cart:** Add, manage, and review selected food items before checkout.
- **Order Management:** View order details and order status.
- **Delivery Tracking:** Track the delivery progress of placed orders.
- **User-Friendly Interface:** Simple and intuitive design for a smooth user experience.
- **Responsive Design:** Accessible across different screen sizes.

## 🎯 Project Objective

The objective of Yum2MyTum is to simplify the food ordering experience by providing a convenient digital platform for browsing food, managing orders, and tracking deliveries.

The project was developed as a learning initiative to explore web development, user interface design, and the implementation of interactive website features.

## 💻 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Akshata2808/Yum2MyTum.git
```

**2. Navigate to the project directory**

```bash
cd Yum2MyTum
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal.

## 📌 Project Scope

Yum2MyTum is a frontend-focused web application. Its current implementation provides the user interface and interactive website experience.

A production-ready food ordering platform would require backend services, database integration, payment processing, and real-time delivery infrastructure.
